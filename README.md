# Retail Sales Data Analysis

## Project Overview

This project analyzes 10,194 retail transaction records to identify sales, profit, discount, regional, category, and customer-segment performance.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- SQL
- SQLite
- Jupyter Notebook
- VS Code

## Data Cleaning

- Checked for missing values
- Checked for duplicate records
- Verified data types
- Created a Profit Margin column
- Found 0 missing values and 0 duplicate records

## Key Business Insights

### Overall Performance

- Total Sales: **$2,326,534.35**
- Total Profit: **$292,296.81**
- Overall Profit Margin: **12.56%**

### Regional Performance

- **West** generated the highest sales and profit.
- **Central** had the lowest profit margin at **7.92%**.

### Category Performance

- **Technology:** 17.45% profit margin
- **Office Supplies:** 17.22% profit margin
- **Furniture:** 2.61% profit margin

Furniture generated more than $754K in sales but achieved only a 2.61% profit margin.

### Discount Analysis

Furniture profitability declined as discounts increased.

- 20% discount → **2.96% profit margin**
- 30% discount → **-10.77% profit margin**
- 40% discount → **-35.49% profit margin**
- 50% discount → **-61.34% profit margin**

**30%+ discounts on Furniture resulted in negative profit.**

### Customer Segment Analysis

- Consumer generated the highest sales and total profit.
- Home Office achieved the highest profit margin at **14.02%**.

## Business Recommendations

- Review high discounts on Furniture products.
- Improve profitability in the Central region.
- Focus on high-margin categories.
- Monitor discount levels before promotions.
- Focus on profitable customer segments and products.
